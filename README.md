# 💼 Fokir Portfolio

## 📌 Overview
Fokir is a modern and fully responsive portfolio website built using only HTML and CSS.  
The project focuses on creating a clean and professional personal portfolio design to showcase skills, services, and work in an elegant way.

---

## ✨ Features
- Fully responsive design for all devices  
- Clean and modern portfolio UI  
- Smooth and structured layout  
- Sections for about, services, and portfolio  
- Simple and elegant design  

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  

---

## 🎯 Purpose
This project was built to practice frontend development skills and improve UI design by creating a professional portfolio website using only HTML and CSS.
